## ✨ ฟีเจอร์หลักของหน้าเว็บ (Features)

* **Dynamic Weekly Cards:** ใช้ JavaScript ในการสร้างการ์ดรายสัปดาห์ (Week 01 - 17) อัตโนมัติ ลดความซ้ำซ้อนของโค้ด HTML
* **Source Code Integration:** มีปุ่ม "Source Code (GitHub)" ในแต่ละการ์ด เพื่อให้อาจารย์สามารถคลิกเข้าไปดูโค้ดของสัปดาห์นั้นๆ บน GitHub ได้ทันที
* **Smart Content Locking:** สัปดาห์ที่ยังเรียนไม่ถึง ปุ่มเข้าชมจะถูกปิดการใช้งาน (Disabled) และขึ้นสถานะ "Coming Soon"
* **Empty State Handling:** มีหน้าแจ้งเตือน (No Assignment) สำหรับสัปดาห์ที่ไม่มีการสั่งงานหรือการสอบ

## 📂 โครงสร้างของโฟลเดอร์ (Repository Structure)

โปรเจกต์นี้ถูกแบ่งหมวดหมู่ไว้อย่างเป็นระบบ ดังนี้:

* 🟢 **`Try-it/`**: โฟลเดอร์เก็บโค้ดตัวอย่างและการฝึกทำในห้องเรียน (Practice)
* 🔵 **`Labs/`**: โฟลเดอร์เก็บชิ้นงานและแบบฝึกหัดที่ได้รับมอบหมาย (Assignments) 
* 🔴 **`Exam/`**: โฟลเดอร์เก็บผลงานสำหรับการสอบ (เช่น `First-exam`, `Second-exam`)
* 📄 **`index.html`, `style.css`, `script.js`**: ไฟล์ส่วนหน้าเว็บหลัก (Landing Page) ที่ใช้แสดงผลรวมของรายวิชา

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)

* **HTML5**: จัดโครงสร้างหน้าเว็บแบบ Semantic (ไม่มีการใช้ Animation ตามโจทย์)
* **CSS3**: ตกแต่งความสวยงาม, Responsive Design (Flexbox/Grid) เน้นความเรียบง่ายและใช้งานสะดวก
* **JavaScript (Vanilla)**: จัดการ DOM, สร้าง UI แบบ Dynamic และจัดการลิงก์สำหรับเชื่อมโยงไปยัง GitHub Repository
